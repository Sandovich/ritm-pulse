# RITM 2.1 · карта продукта

На первом экране человек выбирает знакомство с примером, свой профиль или гостевой вход. После анкеты из 13 вопросов появляется карта DNA и первое действие. Гость переходит из приглашения непосредственно к выбору своего действия. Сменить ответы можно из профиля.

| Точка входа | Маршрут | Что считается результатом |
|---|---|---|
| Сегодня | Неделя → свободное время → действие или ответ на PULSE | Личная отметка, по желанию видимая кругу |
| Питание | Приём пищи / продукты дома → рецепт → порции → корзина | Список продуктов с количествами, избранное, будничное меню, отметка о приготовлении |
| PULSE | Входящий импульс → своё дело → общий круг | Ответ в течение суток, реакция, история, видимость дела, выход из круга |
| Арена | Дуэль, эстафета, командная цель или недельный челлендж → приглашение → табло | Баллы за регулярность, возможность повторной игры. Для совместного занятия можно предложить время |
| Тренировки | Сегодня / личный план / каталог → оборудование → занятие → таймер → запись | День, длительность, подходы и повторения для тренировок; возвращение через короткий вариант |
| Профиль | Личный план → исходный показатель → недельная сверка → RECAP | Личный тренд, добровольные замеры и карточка для отправки только с количеством дней |
| Специалисты и сезоны | Профиль / тематический раздел → роль → предложение → интерес или заявка | FOOD 2 490 ₽, RESET 3 490 ₽, DUO 5 490 ₽ за двоих, без автопродления |

## Визуальная система

Manrope с кириллицей. Фон `#0D0E0D`, поверхность `#171A17`, карточки `#20231F`, акцент `#D5FC53`, текст `#F5F6F2`, подписи `#B1B6AC`, разделитель `#2D302B`, дополнительный зелёный `#A6C85B`. Нижняя панель удерживает пять точек входа. Лайм выделяет входящий PULSE, выбранный элемент и прогресс. Кольцо показывает долю запланированных дней. Цвет дополнен числом или подписью. Фотографии и шрифт загружаются с того же сайта.

Для показа на компьютере сохранён компактный мобильный разворот. Сетка кратна 4/8 px. Учитываются системные отступы iOS, фокус клавиатуры, предпочтение сокращённого движения и состояние загрузки движка. Кнопки и рецепты используют общие компоненты в `web/premium.js`, дизайн-токены находятся в `web/premium.css`.
