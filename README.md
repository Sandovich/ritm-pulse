# ritm.

**Твоя цель. Твой ритм. Твои люди.** Мобильное приложение для людей, которые хотят продолжать свой план питания и тренировок вместе с друзьями. У каждого своя цель. На тренировку друга можно ответить прогулкой или приготовленным ужином.

[Открыть приложение на GitHub Pages](https://sandovich.github.io/ritm-pulse/) · [Экраны и дизайн](DESIGN.md) · [Скриншоты](screenshots/)

## Главный экран на согласование

[Сразу открыть «Сегодня»](https://sandovich.github.io/ritm-pulse/?screen=today) · [Сравнение, три скриншота и запуск](HOME-REVIEW.md). Ветка этого этапа — `design/home-approval`. Пример открывается в отдельном хранилище браузера.

## Пять минут для знакомства

1. Нажми **«Посмотреть демо»**. Появится личный план Саши и входящий PULSE от Лены.
2. Нажми **«Ответить импульсом»**, выбери питание и отметь действие. Открой PULSE, чтобы увидеть его в ленте.
3. В «Питании» выбери ужин, поменяй порции и отправь продукты в корзину. В «Сегодня» открой тренировку и запусти таймер.
4. В «Арене» создай дуэль и нажми **«Открыть за друга»**. Прими приглашение. Переключать профили также можно кнопкой «Демо» вверху.
5. В профиле доступны анкета DNA, личный план, недельная карточка RECAP и три тестовых предложения. Чтобы начать сначала, выбери **Демо → Сбросить демонстрацию**.

«Создать свой профиль» открывает пустой маршрут с анкетой. Просмотр по приглашению позволяет сразу выбрать своё дело.

## Как устроены два режима

| | Демонстрация на GitHub Pages | Серверный пилот |
|---|---|---|
| Участники | Два профиля на одном устройстве | Независимые сессии, гостевые ссылки, восстановление с одноразовым кодом |
| Личные данные | SQLite в браузере, сохраняется между посещениями | SQLite на сервере. Профиль, условия сезона и замеры доступны владельцу |
| Правила | Те же модули Python в Web Worker через Pyodide | Python HTTP API с проверкой прав, времени и повторных операций |
| Уведомления | Центр уведомлений внутри приложения | Дополнительно добровольный Web Push для PULSE, требует HTTPS, VAPID и поддерживаемого браузера |
| Покупка | Учебная заявка без списаний | Витрина и учёт заявок, оплат и возвратов. Для приёма денег нужен настроенный канал оплаты |

Фотографии специалистов иллюстративны. Представлены роли, состав услуг и ориентиры цен. Подтверждение квалификации, расписание консультаций, экспертное утверждение контента, съёмка техники и промышленная интеграция AI относятся к следующему этапу. В интерфейсе работают правила подбора. Партнёрский авторский сезон можно обсуждать после прогона и первого самостоятельного запуска.

## Запуск

Требуется Python 3.11 или новее. Для базовой работы достаточно стандартной библиотеки. Из этой ветки выполни:

```sh
python web/server.py --port 8765
```

Открой [серверное приложение](http://localhost:8765/), [изолированное демо](http://localhost:8765/demo/) или [исходный интерфейс пилота](http://localhost:8765/pilot). Для проверки двумя телефонами в своей Wi-Fi сети укажи `--host 0.0.0.0` и открой адрес компьютера с портом 8765. Для восстановления и пересылки реальных данных за пределами локальной сети нужен HTTPS. Файл базы можно указать параметром `--db`.

Для обновления Pages после изменений в `web/` запусти `python scripts/pages.py`. Ветка публикации этого этапа — `design/home-approval`, папка — `docs/`. Закреплённые версии движка, шрифтов и иконок включены в сборку. Исходный серверный пилот сохранён в `main`.

## Проверка

```sh
python tests/check-rules.py
python tests/check-season.py
python analysis/check-metrics.py
python -m pip install playwright
python -m playwright install chromium
python tests/mobile_smoke.py
```

Для проверки подписи и шифрования Web Push установи `pywebpush` и выполни `python tests/check-push.py`. Проверки используют временные базы и синтетические данные. Для повторной проверки опубликованной версии передай `--url https://sandovich.github.io/ritm-pulse/` браузерному тесту.
